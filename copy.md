# Tutorial Git, GitHub e primeiro commit

## Sobre o livro

Este livro apresenta um tutorial prático para aprender Git e GitHub do zero, desde os conceitos fundamentais até a realização do primeiro commit.

A proposta é ensinar os principais conceitos e comandos do Git, a utilização do GitHub e um workflow básico para versionar e publicar projetos, permitindo que o leitor comece a utilizar controle de versão de forma prática.

## Capítulos

### 1. Introdução ao Git e GitHub

- O que é Git e controle de versão
- História e fundamentos do Git
- O que é o GitHub e sua importância

### 2. Instalação e configuração

- Instalação do Git
- Configuração inicial
- Git, terminal e extensões VS Code

### 3. Primeiro repositório e primeiro commit

- Criação e inicialização de um repositório
- Principais comandos do Git
- Primeiro commit

### 4. GitHub e workflow básico

- Criação de um repositório no GitHub
- Conexão entre Git local e GitHub
- Push, pull e sincronização
- Organização básica do workflow

### 5. Checklist e resumo

- Checklist do projeto
- Principais comandos
- Workflow Git + GitHub
- Resumo do processo completo
